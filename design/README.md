# SQLForge — UI デザイン案

Linux 向け SQL 管理スタジオ（SSMS 相当）のデザイン案。
各 `*.dc.html` が 1 画面（アートボード）で、`canvas.json` がキャンバス上の配置を定義する。

| ファイル | 画面 |
| --- | --- |
| `Main.dc.html` | メインウィンドウ（オブジェクトエクスプローラ + クエリエディタ + 結果グリッド + インスペクタ） |
| `Connect.dc.html` | 接続ダイアログ |
| `Schema.dc.html` | テーブル設計（列定義 + 生成 DDL + 未適用の変更） |
| `ERD.dc.html` | ER 図 |
| `Plan.dc.html` | 実行プランビジュアライザ |
| `Settings.dc.html` | 設定（外観） |
| `Tokens.dc.html` | デザイントークンとコンポーネント一覧 |
| `MainLight.dc.html` | ライトテーマ（Main と同一レイアウト、色トークンのみ差し替え） |

`sqlforge-linux-design.html` は上記をまとめて公開用に書き出したもの。
Avalonia / C# 実装への対応は `avalonia.md` と `avalonia/*.axaml` を参照。

## 方向性

ダークな高密度データツール。3 ペイン構成（エクスプローラ / 作業領域 / インスペクタ）を
全画面で共通にし、画面を切り替えても目線が動かないようにする。

- アクセントは琥珀色 1 色のみ（選択・実行・未保存）
- 青緑はデータそのもの（FK、リレーション、データバー）
- 赤 / 緑は「危険 / 安全」の意味だけに使う
- 面 4 段・テキスト 4 段・境界 2 段に固定する

## 寸法（コンパクト密度・既定）

ツリー行 24px / グリッド行 26px / エディタ行 19px / ツールバー 36px / ステータスバー 24px /
左サイドバー 288px / 右インスペクタ 300–320px
